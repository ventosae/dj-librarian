## Task
Branch `feat/w31-identity-and-report` off `main`. One squash commit: `feat: dj-identity sleeve and report redesign (W-31)`.

1. **`docs/design.md`** — the design system for every HTML this tool renders. Write it from the rules below, then follow it.
   - Tokens as CSS custom properties on `:root`; dark values declared twice: under `@media (prefers-color-scheme: dark)` guarded by `:root:where(:not([data-theme="light"]))`, and under `:root[data-theme="dark"]`; a theme toggle in the page header (two buttons: Booth / Day). Default = Booth (dark). `body` has an explicit background.
   - Surfaces: light `#fcfcfb` text `#0b0b0b` / `#52514e`; dark `#1a1a19` text `#f0efec` / `#c3c2b7`.
   - Categorical hues in this fixed order, never cycled, same slot for the same lane everywhere in the page: 1 blue `#2a78d6`/dark `#3987e5`, 2 orange `#eb6834`/`#d95926`, 3 aqua `#1baf7a`/`#199e70`, 4 yellow `#eda100`/`#c98500`, 5 magenta `#e87ba4`/`#d55181`, 6 green `#008300`/`#008300`, 7 violet `#6250d6`/`#9085e9`, 8 red `#e34948`/`#e66767`. Past 8 → "Other". Sequential (magnitude) = one blue ramp light→dark (`#cde2fb` … `#0d366b`); never a rainbow. Status colours reserved for good/warning/critical with an icon and a label, never used as a series.
   - Marks: thin; 4 px rounded ends on the baseline; 2 px surface gap between adjacent fills; 2 px lines; ≥ 8 px markers; direct labels on ≤ 4 marks, never a number on every point; recessive grid; one axis per chart, never two scales; text in text tokens, never in the series colour.
   - Interaction: hover tooltip on every mark (inline JS, no library); hit targets larger than the mark; a "table" link per chart to the MD/JSON file it came from.
   - Typography: a display face for the hero. Either embed one OFL-licensed font as a subset `data:` URI (≤ 60 KB total, licence text in `docs/design.md`) or use the system stack `ui-sans-serif, system-ui` with size, weight and letter-spacing doing the work. No font URLs.
   - Validation: `scripts/check_palette.py` (stdlib): converts hex → OKLab, checks every adjacent categorical pair for normal-vision ΔE ≥ 15 (×100) and simulated protan/deutan/tritan ΔE ≥ 8, and each slot's contrast against its surface (< 3:1 → the chart must carry direct labels or the table link). Runs in CI on the tokens in `docs/design.md`.
   - Anti-patterns to refuse: dual axis, pie for > 3 slices, rainbow, colour-only identity, numbers on every point, colours assigned by rank, a hue at a diverging midpoint.
