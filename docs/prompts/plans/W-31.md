Written 2026-10-21 before the build. Brief: `docs/prompts/W-31.md` (the PM prompt). Hard rules: CLAUDE.md. Door 1: stdlib + PyYAML only (D-19), one self-contained HTML (R-401), measured by code, words by Claude (R-302).

## Facts found before building

1. **W-30 is not on `main`.** W-31 builds on `1a178b7`. From W-30 it takes only what it needs: `scripts/make_samples.py` and `docs/samples/` (W-30 item 3). W-30's other items stay open.
2. **Tritan.** The fixed palette (order and hexes from the brief = the dataviz reference palette) passes normal vision ≥ 15 and protan/deutan ≥ 8 on adjacent pairs in both modes, but light-mode tritan on the adjacent pair yellow `#eda100` / magenta `#e87ba4` is 5.8 (dark: worst 8.7). The method's CVD gate is protan + deutan (Machado 2009, severity 1.0); its thresholds are calibrated to those. `check_palette.py` therefore gates protan/deutan ≥ 8 and normal ≥ 15 (exit 1 on failure) and reports tritan against 8 as a WARN that obligates relief (direct labels or the table link), which every chart here carries. Q- line for the owner.
3. **Pairs.** Six axes give 15 unordered pairs (30 ordered), not 28 (28 = pairs of eight). The archetype table maps all 15 unordered pairs; the test runs all 30 ordered pairs.

## Identity (R-1401, R-1402)

- `src/dj/analysis/identity.py` (Door 1): `axes(profile, structure, taste, *, today) -> dict` from the facts JSON already written; each axis = `{"score": 0..100 int, "inputs": {...}, "formula": "..."}`. Axis order (also the tie-break): Depth, Selectivity, Discipline, Breadth, Momentum, Memory. Formulas are fixed weights of normalised inputs, clamped, rounded; written in the module docstring and `SKILL.md`. Memory averages only the fields the source carries (no My Tags in XML: recorded as `"my_tags": null`).
- Archetype: the two highest scores (ties by axis order) form an unordered pair; `plugin/skills/dj-identity/archetypes.yaml` holds 8 archetypes, each with `name`, `meaning` (one line), `booth_line`, `pairs` (the unordered pairs it covers); every one of the 15 pairs belongs to exactly one archetype, every archetype owns ≥ 1 pair. Names affectionate, in the voice.
- `profile/identity.json`: `schema`, `source` (export, relative), `seed` (sha256 of the export bytes, hex), `handle`, `axes`, `top` (the two axes), `archetype` (`slug`, `name`, `meaning`, `booth_line`), `lanes` (from taste facts, BPM low→high, each with its palette `slot` 1–8, "Other" past 8), `fingerprint` (rings = decades, segments = BPM bands, cell shares).

## Sleeve (R-1403)

- `src/dj/sleeve.py` (Door 1): `sleeve_svg(identity) -> str` and `mini_sleeve_svg(identity, slots, *, size) -> str`. Square viewBox (12-inch sleeve, 1000×1000). Radial fingerprint: rings = decades, segments = BPM bands, ring thickness / cell opacity = share; segment colour = the lane slot that owns its BPM band. Handle in display type, archetype as subtitle, the three biggest lanes as liner notes. Seeded only by `identity["seed"]` (rotation, grain): same export → identical bytes. Self-contained: no `href` to anything outside the document, no fonts, no scripts. The sleeve is an object: it keeps its own dark finish in both page themes.

## Report (R-405, R-408, R-409)

- Tokens per `docs/design.md` (written first in this PR). `<html data-theme="dark">` by default (Booth); toggle buttons Booth / Day set `data-theme` and remember it in `localStorage` (try/catch); `#day` / `#booth` in the URL wins (used for the screenshots).
- Lane slots: lanes ordered by BPM (identity, not rank) take slots 1..8 once; every chart in the page uses the same slot for the same lane.
- Inline JS ≤ 200 lines in total (toggle, tooltips, copy buttons). No library, no URL.
