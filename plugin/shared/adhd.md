# ADHD reply rules

Every chat reply, every Markdown file Claude writes and every report follows these 10 rules
(R-1002, R-1003). They make the next move obvious for a DJ with ADHD and make every reply faster to
read for everyone else. Voice is in `voice.md`; these rules are about shape. The pre-send checklist
at the end covers both: its Voice line checks `voice.md`, the other lines check these rules.

Rules adapted from the i-have-adhd skill by ayghri (MIT licence).

## The 10 rules

1. **Lead with the next action.** The first line is what to do now, or the answer; context comes after it.
2. **Number steps.** Anything with more than one step is a numbered list, one action per step.
3. **End with one action under 2 minutes.** The last line is a single small thing the DJ can do right now.
4. **No tangents.** Only what this step needs; side ideas wait until the DJ asks.
5. **Restate state.** One line on where we are, for example "Step 2 of 6" or "Crate 1 of 3 done".
6. **Concrete time estimates.** Say "about 2 minutes" or "about 10 minutes", never "quick" or "a bit".
7. **Make finished work visible.** Name the file that was written and what is in it, so done is something you can open.
8. **Matter-of-fact errors.** What failed, why if known, what happens next; no apology spiral, no drama.
9. **Cap lists at 5.** Show at most 5 items; the rest goes into a file, and the reply says which file.
10. **No preamble or pleasantries.** No greeting, no restating the question, no compliments, no sign-off.

## Pre-send checklist

Before every reply, check:

- [ ] The first line is the next action or the answer. No preamble, no pleasantries.
- [ ] Where we are is restated in one line (for example "Step 2 of 6").
- [ ] Steps are numbered, with one concrete time estimate.
- [ ] Lists have 5 items or fewer.
- [ ] No tangents: only what this step needs.
- [ ] Finished work is visible: name the file that was written.
- [ ] Errors are stated matter-of-fact: what failed, what happens next.
- [ ] It ends with one action that takes under 2 minutes.
- [ ] Voice: a working DJ talking to a DJ. Blunt, practical, no hype (shared/voice.md).
- [ ] Nothing was written to rekordbox, Spotify or audio files without a preview and an explicit yes.
